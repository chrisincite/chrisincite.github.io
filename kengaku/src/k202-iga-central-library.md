## 導言

傍晚六點過後，一樓的開架空間仍亮著。清水混凝土的大梁以一定的間距橫過天花，梁與梁之間懸著白色的穿孔 mesh 幕，燈光由幕後透出；書架不沿柱列排成直線，而是由入口向外周呈弧線展開。這裡原本是市廳舍的事務室，天花高約 5.3 公尺。六十年前為辦理戶籍與稅務而設的挑高空間，現在用來放書。

![伊賀市中央圖書館一樓開架空間，清水混凝土的大梁一道道橫過天花，梁間懸著白色穿孔 mesh 幕，金屬環形吊架上掛著裸燈泡，下方是木質長桌、紅色單椅與弧形排列的書架，遠處是整面的鋼框玻璃窗](../img/k202-iga-central-library-01.webp)

*一樓開架空間。梁間的 mesh 幕與吊燈之下，書架呈弧線排列。*

伊賀市中央圖書館位於三重縣伊賀市上野丸之內，所在的建築是坂倉準三建築研究所設計、昭和三十九年（一九六四年）竣工的舊上野市廳舍。市廳機能移出之後，這座建築經 MARU。architecture 改修，一樓、中二樓與地下一樓成為圖書館，二樓成為飯店，令和八年（二〇二六年）四月圖書館開館。我們在同年七月十二日傍晚到訪，在館內停留約三十五分鐘。

## 建築履歷與用途變遷

依鰺坂徹在日本 ICOMOS 發表的事例報告，上野市於昭和十六年（一九四一年）發足。市長豐岡益人看過坂倉準三的羽島市廳舍之後，委託坂倉設計新廳舍。檢討自昭和三十四年開始，但市府先興建市民使用的設施：公民館、西小學校、崇廣中學校、三重縣上野總合廳舍、白鳳公園的 rest house 相繼完成，市廳舍排在這一系列公共建築的最後。坂倉建築研究所的作品頁稱它為上野市中心部公共建築群設計的集大成。

同一份報告記，廳舍的擔當是大阪事務所的西澤文隆等四人，構造設計為平田建築構造研究所，設備設計為櫻井建築設備研究所，施工為錢高組。同時期坂倉設計的羽島、吳、枚岡等市廳舍都是中高層的量體，上野市廳舍則在伊賀上野城所在台地的山腳下低矮地平鋪展開。

平成十六年（二〇〇四年）上野市與周邊町村合併為伊賀市，這座建築改稱伊賀市廳舍，其後面臨改建。平成十九年市長發表原地改建；平成二十一年起市民團體連署並舉辦展覽，DOCOMOMO Japan 提出保存活用的要望書，翌年日本建築學會東海支部也提出要望。平成二十四年，同一建築群中的中央公民館與北廳舍（舊縣上野總合廳舍）先被拆除。同年反對拆除的候選人當選市長，平成二十六年市府決定把市廳舍移轉到別處新建。

此後的保存經過依序是：平成二十七年 DOCOMOMO Japan 選定、翌年 DOCOMOMO Japan 提出把廳舍作為圖書館活用的再生案、平成二十九年入選日本 ICOMOS 的「日本 20 世紀遺產 20 選」、平成三十年底市廳機能移出、平成三十一年（二〇一九年）三月指定為市指定有形文化財。令和二年市府公布保存活用計畫並進行市場調查；令和三年十月公告 PFI 事業，令和四年九月簽訂約二十年的 PFI 事業契約。

依《新建築》刊載的設計者文字，令和四年的公募以圖書館為中心，設計者所屬的事業者團隊提出併設飯店的方案而獲採用。令和七年（二〇二五年）七月，二樓的飯店「泊船」與一樓的咖啡館、觀光案內所先行開業；圖書館於翌年四月一日開館，名稱由「上野圖書館」改為「伊賀市中央圖書館」。依伊賀市的報導，圖書館的樓地板面積約 3,600 平方公尺，占全棟約六成，藏書約二十三萬冊。

## 基地配置與都市脈絡

依《新建築》的配置圖，舊廳舍位於伊賀鐵道上野市站北側，與站前廣場只隔一條國道 25 號；再往北是上野公園與伊賀上野城。基地是通往城址的斜面途中的一段，圖說記南北約有 2 公尺的高低差；構造計畫研究所的資料記北側較高，北側因此設有部分地下層。

![舊上野市廳舍南側外觀，前景是寬闊的混凝土大階段，後方是長向延伸的二層清水混凝土量體，二樓以水平帶窗與出挑的樓板構成，一樓退後成玻璃面，右側樹林之後是上野公園的丘陵](../img/k202-iga-central-library-02.webp)

*自南側大階段望向舊廳舍。長向的二層量體貼著台地的山腳展開。*

站前廣場與廳舍之間是一片低緩的混凝土大階段。廳舍的長邊朝南，二樓的量體以水平帶窗連續，一樓則退後成整面的鋼框玻璃。依坂倉建築研究所的說明，二樓量體由東西向、以 4.6 公尺等距排列的壁柱支撐；鰺坂徹的報告記這道列柱延續約 75 公尺。

《新建築》的配置圖另標出兩棟現存的坂倉作品：上野公園內的 rest house（昭和三十八年竣工）與上野西小學校的體育館（昭和四十一年竣工）。站前的南側則有同一 PFI 事業新建的忍者體驗設施，設計同為 MARU。architecture。

## 空間序列及其效果

依《新建築》的圖說，一樓原為事務室的空間天花高約 5.3 公尺，寬約 37 公尺，進深約 27 公尺；改修後整片作為一般開架。設計者把無斷熱性能的窗周邊定位為「半屋內」，在樓板輻射空調的區域與簷下的半屋外之間設一圈半空調的過渡帶；樓板自外周往中央墊高 140 毫米。

*入口旁的櫃台與階段。斜向的清水混凝土牆沿階段升起。*

自入口進入，左手是一道沿階段斜向升起的清水混凝土牆，前方是一座頂面白色、立面貼六角形磁磚的長櫃台。《新建築》的圖說記，這座入口櫃台的六角形磁磚與斜向型枠的階段壁都是原有的。斜牆的另一側是通往中二樓的階段。

![一樓的 S 形櫃台，木質面板的櫃台呈 S 形彎曲，後方是整面鋼框玻璃窗，窗外是站前的街道與建物，天花上方可見清水混凝土大梁與白色的 mesh 幕](../img/k202-iga-central-library-04.webp)

*S 形的櫃台。窗外是站前的街道。*

開架空間的中央是一座以木質面板構成、呈 S 形彎曲的櫃台。櫃台後方是南側整面的鋼框玻璃窗，窗外即是站前的街道；《新建築》的圖說記南側與東側的窗框為既存。從櫃台的位置，視線可以穿過整個開架空間抵達南窗。

![一樓開架空間的天花，清水混凝土大梁一道道平行排列，梁間懸著白色的穿孔 mesh 幕與條狀照明，下方是黑色鋼框的弧形書架，遠處是鋼框玻璃窗與窗外的樹木](../img/k202-iga-central-library-05.webp)

*梁間的 mesh 幕。黑色鋼框的書架沿弧線排列。*

天花保留了原有的格子梁。設計者在梁與梁之間懸掛 mesh 幕，文字說明其用意：讓柱梁維持外露，同時在幕上方留出設備日後可以自由通行的明亮餘白。書架則依圖說「自中央入口向外周呈流線且放射狀」配置，並寫明書架的排列兼為引導自然通風。照片中，書架不沿柱列的方向排列，而是以弧線切過柱間。

![自一樓開架空間的一端望向另一端，兩側是一排排粗壯的清水混凝土方柱，柱頂承接大梁，梁間是連續的白色 mesh 幕，下方是圓桌閱覽區與弧形書架，最深處是另一端的牆面](../img/k202-iga-central-library-06.webp)

*沿柱列方向的縱深。方柱與大梁的節奏直達對側。*

沿柱列方向看，方柱與大梁的節奏一直延續到對側。弧形書架的高度約在視線上下，柱列、梁與 mesh 幕的重複因而不被書架遮斷；書架的弧線與柱梁的正交格子在同一個視野中重疊。

![自中二樓俯看一樓入口一帶，左下是櫃台的一角，中央是一根清水混凝土方柱，右側是頂面白色的入口櫃台與下行的階段，遠處是開架空間、紅色單椅與成串的吊燈](../img/k202-iga-central-library-07.webp)

*自中二樓俯看入口一帶。*

斜牆旁的階段通往中二樓。中二樓位於挑空的一側，可以俯看一樓的入口、櫃台與開架空間。這段樓層是廳舍原有的構成；構造計畫研究所的資料記，原建築因北側地盤較高，北側為三層、南側為兩層的挑空，一樓的樓板高度並不一致。

![自中二樓俯看一樓的書架，黑色鋼框與木質的書架呈弧線一排排展開，書架之間是淺色的通道，上方是清水混凝土方柱、大梁與 mesh 幕，遠處是鋼框玻璃窗](../img/k202-iga-central-library-08.webp)

*自中二樓俯看書架。弧形的書架在柱間一排排展開。*

自上方看，弧形書架的配置最為清楚：書架與書架之間的通道不是直線，而是一條條曲線，在方柱之間穿過。

![中二樓的閱覽區，數張木質圓桌與木椅散置，學生在桌前讀書，後方是一排有隔板的個人座位、清水混凝土牆與一間玻璃隔間的房間，天花是清水混凝土梁與白色 mesh 幕](../img/k202-iga-central-library-09.webp)

*中二樓的閱覽區。*

中二樓配置圓桌的閱覽區與附隔板的個人座位，天花同樣是外露的梁與 mesh 幕。傍晚時段，這一層的座位多由學生使用。

![白色牆面上展示著大幅的古城下町繪圖與說明立牌，上方是一道清水混凝土大梁斜過畫面，梁上方是白色的 mesh 幕](../img/k202-iga-central-library-10.webp)

*展示牆。大幅的城下町繪圖貼在白牆上。*

館內有一段白牆作為展示之用；拍攝時展示的是大幅的古城下町繪圖。《新建築》的圖說記，頂光下方設為依時期更換主題的展示空間。

![一座階段梯間，兩側是木質突板的牆面，正前方是一扇大窗，窗外可見遠處的山稜與市街，下方的梯段沿白色扶手轉折而下，混凝土的樓板邊緣在窗前橫過](../img/k202-iga-central-library-12.webp)

隔著長廊的窗可以看到中庭。中庭的地面覆滿綠色的地被植物，邊緣是一排斜置的玻璃頂光。坂倉建築研究所的說明寫道，「日」字形平面的二樓設有中庭，光經由中庭的頂光導入一樓；設計者則寫道，這兩個中庭向天空開放，過去把光送到一樓。一樓所見的展示空間，即位於這些頂光的下方。

## 構法與材料

依《新建築》的資料，這座建築為鋼筋混凝土造，地下一層、地上二層，改修後總樓地板面積 6,069.78 平方公尺，改修的工期為令和六年（二〇二四年）八月至翌年十二月。構造計畫研究所的資料記原構造為附耐力壁的剛構架，二樓議場 13 公尺跨的屋頂在施工時由鋼筋混凝土改為鋼桁架。

![一樓天花的仰視，清水混凝土大梁表面留有杉板模板的木紋，梁間懸著白色的穿孔金屬板，板的兩側是條狀的照明，下方是鋼框玻璃窗](../img/k202-iga-central-library-18.webp)

*梁與 mesh 幕的仰視。梁面留有木紋模板的痕跡。*

構造補強集中在不破壞挑空的位置。構造計畫研究所的資料記，一樓南北向不足的耐力，以南側既有混凝土牆增打與中二樓兩道鋼斜撐補足，以保住南側被列為保存部位的挑空空間；屋上高約 16 公尺的煙囪以鋼筋混凝土根卷補強至二樓樓板以上 6.2 公尺，《新建築》的圖說記根卷厚 200 毫米。

地面的六角形磁磚也是保存的對象。《新建築》的圖說記，一樓存有新舊磁磚的交界，復原的磁磚由多治見燒製；書架以 16 毫米見方的鋼框構成，用以呼應既存的鋼窗。另一方面，依鰺坂徹的報告，坂倉設計的天花與廻緣細部，因成本與設備計畫的問題在改修時拆除，換成光滑的新天花，原有的目地與廻緣由教育委員會實測記錄。

## 附設商店與餐飲

依 SAKAKURA BASE 官網，令和七年七月十九日與館內的翻修同日開業的有三處：土產店「伊賀百貨」、觀光案內所「伊賀市觀光 Information Center」與咖啡館「CROSS CAFE」。三重縣觀光連盟的資料記，觀光案內所營業時間為九時至十八時，十二月二十九日至一月一日休業；伊賀百貨販售伊賀的傳統工藝、特產與點心。

《新建築》的一樓平面圖上，咖啡館與飯店的櫃台相鄰，觀光案內所位於玄關大廳旁；這些設施與圖書館同在一樓，不需門票即可進入。飯店「泊船」的入口與櫃台依圖說設在北側，依《新建築》，飯店的客室五改修前是市長室，天花高 2,190 毫米。

## 保存運動與公私協力

這座建築從決定拆除到成為圖書館，歷時約十五年。鰺坂徹的報告記，市府曾在平成二十二年表明拆除廳舍改建，同一建築群中的中央公民館與北廳舍在平成二十四年被拆除；廳舍得以保留，是市長更替與市民持續參與保存活動的結果。平成二十八年 DOCOMOMO Japan 提出的再生案，已經把一樓與中二樓作為圖書館開架空間。

再生最終以 PFI 的方式實現。依報告，事業者團隊由一家代表企業與六家構成企業組成，其中包括圖書館營運、設計、施工與展示的公司，設計者 MARU。architecture 也是成員之一。報告同時記錄了這種方式的代價：保存委員會反對的挑空新設階段與舊市長室的改變，因事業的收益性與法規仍然實施；坂倉的天花細部也未能保存。作者據此指出，近現代建築的保存再生，需要就應保存的價值與部位持續累積事例與討論。

地方報紙以「日本第一座可以住宿的公共圖書館」形容這座建築。一樓開架空間在晚間九時之前持續開放；構造計畫研究所的資料記，二樓的客室由舊廳舍的市長室與議員室改成。

## 散策建議

圖書館上午九時開館，晚間九時閉館。伊賀鐵道上野市站就在館的南側，徒步約五分。本篇的路線以上野市站為起點，先往東到上野天神宮，再折向西穿過城下町，經館前上到上野公園，繞伊賀上野城與俳聖殿一周之後，以館為終點。全長約 3.0 公里，純步行約四十三分。
