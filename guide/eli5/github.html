GitHub
是做什麼的？

七張圖。看完你就懂了。

01

你一定遇過這個

改到最後，自己也不知道哪一個才是對的。

GitHub 就是來解決這件事的。
你不用再自己想檔名了。

02

它幫你「按存檔」

就像打電動，衝去打大魔王之前先存一次。

改壞了？退回上一個點就好。

這個存檔點叫 commit

03

存檔放在一個箱子裡

一個作品，一個箱子。電腦有一個，雲端有一個。

筆電被咖啡潑到也沒關係。雲端那份還在。

箱子叫 repository（repo）· 推上去 push · 拉下來 pull

04

想亂搞？先影印一份

在影印本上盡情實驗，正本一根寒毛都沒動到。

失敗就整份丟掉。沒有人會知道。

影印一份叫 branch · 合併回來叫 merge

05

有三樣東西不要放進去

箱子很好用，但它不是什麼都能裝。

存檔點是刪不掉的。
今天貼上去的密碼，明天刪也來不及。

06

要給程式用，得發一張房卡

程式沒辦法去你手機上看驗證碼。

那串字只會顯示一次。
看到就立刻複製，存進密碼管理器。

房卡叫 personal access token

07

然後你可以用講的

這兩年才成立的事：你不用記那些指令了。

但有一條線要守住：
「推上去」這個動作，留給你自己點頭。

今天只要做一件事

申請一個免費帳號，開一個只有自己看得到的箱子。
然後按一次存檔。
