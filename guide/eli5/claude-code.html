Claude Code
在幹嘛？

八張圖。看完你就懂了。

01

聊天視窗 vs. 走進工作室

同一個 Claude，但站的位置完全不同。

黑色畫面不是為了看起來厲害。
工具都在那裡，所以它得待在那裡。

02

session ＝ 一次坐下來

從打招呼到你關掉視窗，中間講的每一句它都記得。

一個 session，只做一件事。
理由不是潔癖——看下一張。

03

token ＝ 計程車的跳表

AI 不是一個字一個字讀，是切成小塊讀。

這是計價單位，也是一切限制的單位。

04

context ＝ 固定大小的工作桌

六個詞裡最重要的一個。AI 其實沒有記憶——它每次回答，都把整包對話重讀一遍。

對話越長，後面每一句都越貴——因為每一輪都要把整包重讀一次。
長度變兩倍，之後每一輪都按兩倍重送。

實測：一個月 200 多場對話，聊很久的那 17% 吃掉 九成以上的用量

05

memory ＝ 貼在牆上的規矩

session 會散、桌子會滿。那有沒有「講一次就永遠算數」的？

session 是每天的對話。
memory 是貼在牆上、每個進來的人都會看一眼的那張紙。

06

skill ＝ 需要時才翻開的手冊

有些事一個月才做一次。塞進「牆上的規矩」，剩下二十九天都在白佔桌子。

這叫漸進式載入：需要才讀，不需要就不佔位置。

skill 就是一個資料夾，裡面一份 SKILL.md，用中文白話寫清楚「什麼時候用、怎麼做」就行

07

MCP ＝ 萬用轉接頭

電腦以外的東西——雲端硬碟、專案系統、地圖服務——它要怎麼碰得到？

USB 出現以前，每種裝置各有各的插頭。
MCP 之於 AI，就是 USB 之於滑鼠鍵盤。

08

三個一定會踩的坑

不是它不好用，是這三件事你沒先知道。

它負責做，你負責驗收。
驗收不能外包給施工的人。

今天只要做一件事

打開終端機，貼一行裝起來，在一個資料夾裡打一次 claude。
第一句話不用問技術問題，就問它：「這個資料夾裡面有什麼？」
