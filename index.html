02 / WORKS

正在長大的東西

每一個都是「一個人＋AI」跑起來的流程：從日本建築雜誌的向量檔案庫，到寫給 LLM 讀的維基，到即開即刪的雲端 GPU 工具。

01

日本建築檔案庫

把《新建築》《住宅特集》《商店建築》十餘年的掃描誌面，逐件翻譯改寫成繁體中文敘事，入庫 Weaviate 向量資料庫，超過兩千件作品可語意檢索。

WeaviateClaude Code批次管線
02

archwiki

建立在檔案庫之上的理解層：建築師、構法、空間概念、地域與年代的跨案例編譯頁——檢索給答案，wiki 給脈絡。

LLM-Wiki繁中
03

arch-drawing-wiki

教 LLM 讀懂日本建築設計圖面的教材：平面図、断面図、矩計図、通り芯……從裁圖到逐案讀圖筆記，再編成跨案主題頁。

讀圖識讀JIS A 0150
04

japan-bussan-wiki

日本各地特色物產的風土誌：関さば、大間まぐろ、廣島牡蠣……一級產品與加工品並重的 LLM-Wiki。

LLM-Wiki風土
05

即拋式 GPU 工具箱

RunPod 上即開即刪的 GPU 伺服器：整本掃描雜誌的雲端 OCR、零樣本聲音克隆 TTS、讓照片開口說話的影片生成。跑完整台刪除，零閒置費。

RunPodOCRTTS
06

聲音克隆工作流

用自己的聲音把文章讀成語音檔，再接字幕影片一條龍：文字 → 克隆 TTS → 跑馬燈或卡拉 OK 逐字反白字幕。

Qwen3-TTSffmpeg
07

建築案例宣傳包

把一個建築案例做成一整套社群宣傳：繁中行銷長文、Editorial 風圖卡輪播、直式 Reels 影片，一個指令生成。

gpt-imageReels
08

每日工作記錄

每天把和 Claude 協作的過程寫成 Facebook 貼文加一張情境插圖——為什麼做、怎麼做、成果如何，留下一人團隊的航海日誌。

自動化MCP
03 / ABOUT

在 AI 時代重建工作流的人

我相信一個人加上 AI，
可以是一整個工作室。

我是 Chris，建築與室內設計背景。過去這段時間，我把日常工作一件一件改寫成「與 Claude 協作」的流程：日本建築雜誌的翻譯與入庫、寫給 LLM 讀的維基、需要算力時即開即刪的雲端 GPU。

方法很簡單：把重複的事交給管線，把判斷留給自己。每一條流程都先手動跑通一次，寫成 skill，之後就變成一句話能啟動的工作。

這個網站本身也是同一種做法的示範——沒有框架、沒有建站工具，就是一個和 Claude 一起手刻的 HTML 檔，放在 GitHub Pages 上。
