## 導言

早上七點半，王橋上已經有人穿著浴衣走過。橋下是大谿川，石造的護岸兩旁種著柳樹，河對岸的山頂剛照到太陽。

![清晨的石橋上，兩位穿浴衣的人走過，橋頭立著石燈籠，背景是河岸的房子與遠山](../img/o013-kinosaki-01.webp)

*清晨的王橋。*

城崎溫泉位於兵庫縣豐岡市城崎町，夾在三面山之間的狹長谷地，大谿川從中流過，再注入圓山川。依環境省的調查，半徑五百公尺內聚著七處外湯與七十多間旅館和土產店。令和七年（二〇二五年）十一月一日傍晚我們到這裡過夜，隔天早上沿著河散步，之後離開。

## 白鸛、道智上人與集中配湯

城崎有兩則開湯傳說，湯島財產區都有記載。一則說約一千四百年前，一隻腳受傷的白鸛降在田裡，把腳浸在水中，幾天後精神抖擻地飛走，村人一查，那裡湧著溫泉，這就是鴻之湯的起源。另一則說養老元年（七一七年），道智上人來到此地，為救難病之人修行一千日，養老四年滿願之日掘地，溫泉湧出，人稱「曼陀羅湯」。觀光協會把後者當作城崎溫泉的開端。天平十年（七三八年），聖武天皇賜溫泉寺「末代山溫泉寺」之號，這座寺從此是溫泉的守護寺；依豐岡觀光，今天數位化的外湯券，起源就是在溫泉寺領受的湯杓。

江戶中期，醫師香川修德在享保十九年（一七三四年）寫的《一本堂藥選》裡，稱城崎的「新湯」為天下第一，這處浴場因而改名「一之湯」。

外湯為中心的格局，是吵出來的。依財產區，昭和二年（一九二七年）有一家旅館在自己的土地上引溫泉，在館內設了浴槽，引發長年的訴訟，到昭和二十五年（一九五〇年）三月才和解：溫泉的利用權全部歸湯島財產區，外湯與內湯並置，內湯另受各種嚴格限制。財產區自昭和三十一年（一九五六年）十月起對旅館配湯。

現在的配湯是集中管理。財產區管理四個泉源（二十七到三十號泉，其中二十九號泉休止中），各泉源湧出的溫泉在兩座儲槽（一百八十與一百立方公尺）裡混合，送進埋在地下的環狀管線，外湯與旅館從各自的支管取用；用過的溫泉排入下水道，不回流到環狀管。

## 震災、外湯與弓形橋

今天的城崎街景，是震災後重建的。依財產區，大正十四年（一九二五年）五月二十三日，圓山川河口外海約八公里處的海底滑動引發地震，全町幾乎毀滅，死者二百七十二人，傷者一百九十八人。所幸泉源沒有大損，町設立復興計畫委員會。依豐岡市，當時的町長、老舖旅館西村屋的當主西村佐兵衛主導的復興計畫，不只是復原：共同浴場重建、道路與橋梁擴寬、區畫整理。觀光協會寫道，地主決定無償提供一成土地，道路拓寬為兩倍，大谿川拓寬並墊高護岸。財產區說，外湯優先復原，大正十五年到昭和七年（一九二六〜一九三二年）間，六處浴場全部新建，昭和十年（一九三五年）溫泉街的骨架大致完成。

依兵庫縣「兵庫水百景」的說明，町請早稻田大學教授岡田信一郎設計一之湯、曼陀羅湯等建築，以及大谿川的護岸與橋梁；六棟外湯與小學校以鋼筋混凝土重建，兼作防火，旅館則保留木造的風情。岡田的風格最集中在桃山樣式的一之湯。現在的一之湯經過改建，設計事務所的作品頁記建築年平成十年（一九九八年），鋼筋混凝土地上兩層、地下一層，八百九十四平方公尺，復原了岡田設計當初的外觀；財產區的年表則記平成十一年度完成改建，內部加入半露天的洞窟風呂。

觀光協會用一句話形容城崎：車站是玄關，道路是走廊，旅館是客房，土產店是賣店，外湯是大浴場。依環境省的資料，城崎溫泉的正裝是浴衣配木屐。平成二十九年（二〇一七年），豐岡市施行城崎溫泉地區歷史建築物保存活用條例，溫泉街也劃為景觀形成重點地區。志賀直哉在大正二年（一九一三年）十月到三木屋療養約三週，四年後發表〈在城崎〉；三木屋昭和二年建的木造西館，平成二十六年（二〇一四年）登錄為有形文化財。

## 泉質與七處外湯

財產區標示的泉質是鈉・鈣－氯化物高溫泉（低張性、中性、高溫泉）；觀光協會寫鈉・鈣－氯化物・高溫泉，外湯的浴槽溫度四十二度。豐岡觀光說源泉約五十七度。

七處外湯，各有來歷：

- **鴻之湯**：白鸛傳說的浴場，庭園露天風呂。
- **曼陀羅湯**：道智上人的傳說，觀光協會說建築自古就是唐破風樣式，平成十二年度改建，加入陶製的桶風呂。
- **御所之湯**：《增鏡》記文永四年（一二六七年）安嘉門院入浴，外湯中唯一的全露天庭園風呂；依神戶新聞，令和二年（二〇二〇年）十一月二日整修後重開。
- **一之湯**：半露天的洞窟風呂。
- **柳湯**：傳說從移植自西湖的柳樹下湧出，平成十六年（二〇〇四年）二月以木造改建，外湯中最小，浴槽深、湯溫高。
- **地藏湯**：相傳泉源裡出了地藏尊，是「村人的外湯」，平成四年（一九九二年）與舊里之湯合併新建，有親子浴槽。
- **里之湯**：車站前，平成十二年七月落成，令和六年（二〇二四年）四月一日起長期休業，重開時間未定。

![紅磚外牆的浴場，入口上方是弧形的屋簷，左右掛著寫有地藏湯的招牌與暖簾，旁邊是一棟白色多層建築](../img/o013-kinosaki-08.webp)

*地藏湯。*

依財產區，外湯每處大人八百元日幣、兒童四百元，營業時間早上七點到晚上十一點（柳湯與曼陀羅湯下午三點起），一日券大人一千五百元，以上為令和八年（二〇二六年）十月的公告；住宿客由旅館借用數位外湯券。鴻之湯自令和八年五月起為延長壽命工程長期休館，重開日財產區寫十月二十八日，觀光協會寫休館至十月三十日（預定）。入湯稅一人一天一百五十元，只泡外湯的人免稅。

![石座上的告示板是城崎溫泉的街區散步地圖，以插畫標出外湯、河川與道路](../img/o013-kinosaki-09.webp)

溫泉也可以喝。財產區設在車站前、藥師公園與王橋的三處飲泉場，豐岡觀光的建議是一次一百到一百五十毫升，一天二百到五百毫升，十五歲以下非經醫師指導最好不要喝。

## 散策建議

我們只在早晨沿河走了地藏湯到一之湯這一段。完整走一遍外湯，可以從地藏湯往上游走到纜車山麓站，再搭纜車上溫泉寺與大師山；車站到地藏湯約零點五公里，步行約七分鐘。觀光協會說，城崎有二十三座文學碑，走一圈約一到兩小時。

![城崎溫泉散策路線圖，自地藏湯沿大谿川往上游，經柳湯、一之湯與王橋、御所之湯、曼陀羅湯、鴻之湯到纜車山麓站，再以虛線標出纜車往溫泉寺](../img/o013-kinosaki-map.webp)

*城崎溫泉散策路線圖。地藏湯到纜車山麓站約一點二公里，步行約十六分鐘；纜車到山頂站約七分鐘。正北朝上。*

1. **地藏湯 → 柳湯**（約 0.2 公里）：沿途經過桃島橋等弓形橋。志賀直哉的自筆文學碑與城崎文藝館在河的南側；文藝館自令和八年九月十四日起臨時休館，以官網公告為準。
2. **柳湯 → 一之湯・王橋**（約 0.1 公里）：王橋邊有飲泉場，一之湯旁有一處足湯。
3. **一之湯 → 御所之湯**（約 0.2 公里）：途中的木屋町小路，依豐岡觀光，平成二十年（二〇〇八年）以「和風的熱鬧」為主題開設。御所之湯西側是三木屋。
4. **御所之湯 → 曼陀羅湯**（約 0.2 公里）。
5. **曼陀羅湯 → 鴻之湯**（約 0.3 公里）。
6. **鴻之湯 → 纜車山麓站**（約 0.1 公里）：纜車昭和三十八年（一九六三年）五月開始營運，斜長六百七十六公尺，最大高低差二百公尺，到山頂約七分鐘，中途停溫泉寺站。山頂站在標高二百三十一公尺的大師山。溫泉寺本堂是至德年間（一三八四〜一三八七年）中興的清禪法印營造的五間四面佛堂，國家重要文化財；本尊十一面觀音立像也是重要文化財，每三十三年開帳一次，依豐岡觀光，下一次在令和三十三年（二〇五一年）。
