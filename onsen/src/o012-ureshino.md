## 導言

早上八點多的溫泉街還沒醒。電線在天空裡交錯，路邊一間酒行掛著清酒的招牌，隔壁是寫真館，街的盡頭是一排低矮的山。

![晴朗早晨的街道，電線橫過藍天，左側是一棟白牆的老店與掛著清酒招牌的店面，街道筆直延伸到遠處的山](../img/o012-ureshino-01.webp)

*早晨的嬉野溫泉街。*

嬉野溫泉位於佐賀縣嬉野市嬉野町，沿塩田川上游的嬉野川兩岸展開。令和七年（二〇二五年）四月二十九日，我們傍晚從武雄過來，晚上住進溫泉街上的宿屋 Uchiroji，隔天早上離開。這一趟是九州行的後段，前幾天走過由布院與霧島。

## 白鶴、風土記與湯宿

嬉野溫泉觀光協會介紹的開湯傳說是這樣的：神功皇后征戰歸來路過此地，看見一隻白鶴把受傷的翅膀浸在河中，不久便精神抖擻地飛走；讓負傷的士兵入水一試，原來河裡湧著溫泉，傷很快就好了。皇后脫口說出「啊，真高興」，這句話就成了「嬉野」地名的由來。

文字記錄可以追到《肥前國風土記》。藤津郡「鹽田川」一條寫道，川源有深淵，「東邊有湯泉，能愈人病」，井上通泰的校注指出這處湯泉就是今天的嬉野溫泉。風土記的成書年代，觀光協會與配湯公司寫和銅六年（七一三年），武雄市則寫七三〇年前後。

江戶時代，嬉野是長崎街道上的宿場。依國土交通省九州地方整備局的整理，嬉野宿以湯宿聞名，宿場中央有藩營的浴場，從大名到庶民都來泡，但浴場依身分細細區隔；本陣設在瑞光寺，大名、長崎奉行與荷蘭商館長都在那裡過夜。文政九年（一八二六年）西博德隨商館長赴江戶途中也到過這裡，國土交通省引他的紀行，記下浴場是簡樸的兩層杮葺建築，浴槽內側以石圍成，長約一點八公尺。

![牆上的黑框裡掛著一張黑白老照片，一條兩側是木造町家的街道，路上站著幾個孩子與行人](../img/o012-ureshino-02.webp)

*旅館休憩室裡掛的老照片，拍的是昔日的街景。*

鐵路一度與這裡無緣。令和四年（二〇二二年）九月二十三日，西九州新幹線武雄溫泉到長崎段通車，嬉野溫泉站在溫泉街東北約二公里處，步行約二十五分鐘。

## 古湯、西博德之湯與新的旅館

溫泉街的象徵是公眾浴場。依佐賀新聞的回顧，這座「古湯」江戶時代屬蓮池藩所有，明治時期由地方有力人士共同出資改建成近代建築，大正十一年（一九二二年）溫泉街大火時全毀，兩年後的大正十三年（一九二四年）以哥德式建築重建。古湯因老朽自平成八年（一九九六年）關閉，平成十七年（二〇〇五年）六月十一日拆除。嬉野市在平成二十二年（二〇一〇年）四月重新開放，名為「西博德之湯」，依市的說明，是再現哥德風格的木造兩層建築，約七百五十平方公尺，橘色的尖屋頂立在嬉野溫泉公園的對岸。現在的建築是重建的，不是大正年間的原物。溫泉街本身沒有列入傳統建造物群保存地區或景觀地區。

我們住的宿屋 Uchiroji 是令和六年（二〇二四年）三月開業的新旅館，客房三十九間。官網寫，這塊基地原是寶曆年間（一七五一〜一七六四年）創業、嬉野最老的竹屋旅館，新旅館把舊館的名字留給了大浴場：男湯叫「竹屋」，女湯叫「寶曆」。館名取自茶道的「露地」，也就是茶室外側那片開放的茶庭。旅館由嬉野的老舖料理旅館吉田屋一系經營。

## 泉質與入浴

依嬉野市，西博德之湯的泉質是鈉－碳酸氫鹽・氯化物泉，一般通稱重曹泉。嬉野溫泉配湯公司公布的共同指標是：泉溫八十五到九十五度，弱鹼性，pH 七點五到八點五，每公斤含鈉四百到五百毫克；佐賀縣觀光則寫源泉溫度八十五到九十度。

溫泉的量是近年的難題。依朝日新聞令和七年（二〇二五年）一月的報導，地下的湯溜裡鑿了十八處源泉，供旅館與飯店取湯；市有源泉的水位從令和三年（二〇二一年）平均四十九點九公尺，急降到前一年的歷史低點四十點八公尺，縣依溫泉法要求節約，把每天約三千二百噸的用量壓到二千八百噸。平成二十年（二〇〇八年）市的審議會曾建議集中管理配湯，因有反對意見，沒有實現。

「日本三大美肌之湯」是嬉野常見的稱號，與島根的斐乃上溫泉、栃木的喜連川溫泉並列。這不是官方認定；栃木縣櫻市的說明是，三處溫泉因泉質相近，彼此合作宣傳。

Uchiroji 的大浴場官網形容為「簡潔而沉穩的設計」，有內湯、露天與三溫暖，三溫暖以嬉野茶澆石生成蒸氣；開放時間下午三點到午夜、早上六點到九點，以官網為準。早上七點我們去泡，深色磁磚的浴槽裡亮著藍綠色的燈，水清澈到看得見池底。

## 宿與飲食

晚餐我們沒有在旅館吃，走到溫泉街西側一間居酒屋。點了生魚片拼盤、握壽司、章魚沙拉與玉子燒，配一瓶清酒。

嬉野的名物是溫泉湯豆腐。依佐賀縣觀光的說明，用溫泉水慢慢煮豆腐，湯汁會漸漸變成豆漿色，豆腐煮得軟滑；觀光協會說，弱鹼性與鈉含量正是豆腐化開的條件。Uchiroji 的早餐是自助式，官網的現行菜單列有溫泉湯豆腐；我們那天盛了香腸、烤鮭魚、水煮蛋、燉菜與生菜，配白飯與牛奶。

![兩只分格木托盤上放著香腸、烤鮭魚、水煮蛋、燉菇與青菜，旁邊是白飯、牛奶、茶與優格](../img/o012-ureshino-14.webp)

*自助早餐。*

另一樣是茶。依嬉野市茶業振興課的報告，嬉野以全國少見的釜炒製玉綠茶與蒸製玉綠茶為主，兩者都把茶葉揉成圓捲形；釜炒茶占日本茶產量不到百分之一。「嬉野茶」的名稱在平成二十年（二〇〇八年）六月十三日登錄為商標。市內的「嬉野大茶樹」在大正十五年（一九二六年）十月二十日指定為國家天然紀念物，推定樹齡約三百七十年。Uchiroji 館內有茶櫃台與茶葉販售區，也有手揉茶與調配茶葉的體驗。

![木檯上陳列著許多金屬茶罐與茶包，每一組前面立著小卡片說明](../img/o012-ureshino-15.webp)

*館內陳列的茶罐。*

旅館一樓臨街是一間巧克力店。依官網，店裡的嬉野熔岩巧克力蛋糕在佐賀伴手禮評選中拿到嬉野市部門第一，另有用嬉野茶焙茶做的口味。

## 散策建議

溫泉街不大，從旅館出發繞一圈只要二十分鐘。要走得更遠，可以往西南接轟之瀑，或往東北走到新幹線站。

![嬉野溫泉散策路線圖，自宿屋 Uchiroji 出發，經西博德之湯、西博德足湯、湯宿廣場、豐玉姬神社到北側的瑞光寺，再回到旅館](../img/o012-ureshino-map.webp)

*嬉野溫泉散策路線圖。溫泉街一周約一點四公里，步行約二十分鐘。正北朝上。*

1. **宿屋 Uchiroji → 西博德之湯**（約 0.2 公里）：開館早上六點到晚上十點，每月第三個週三休館，大人四百五十元日幣，以市的公告為準。
2. **西博德之湯 → 西博德足湯**（約 0.1 公里）。
3. **西博德足湯 → 湯宿廣場**（約 0.2 公里）：足蒸湯在這裡。
4. **湯宿廣場 → 豐玉姬神社**（約 0.2 公里）：祭神豐玉姬命。依觀光協會，神社在江戶時代的宿場中央，旁邊是上使屋與人馬繼立所。依佐賀縣觀光，自古有許多湯治客來此祈求皮膚病痊癒，如今以美肌之神為人所知。
5. **豐玉姬神社 → 瑞光寺**（約 0.3 公里）：嬉野宿的本陣。依國土交通省，本尊藥師如來相傳是運慶所作。
6. **瑞光寺 → 宿屋 Uchiroji**（約 0.4 公里）。

延伸：從豐玉姬神社往西南約一點七公里是轟之瀑，依佐賀縣觀光，高十一公尺，分三段落下，瀑潭約二千五百平方公尺；公園裡的日子山橋因吊索斷裂，目前封閉。
