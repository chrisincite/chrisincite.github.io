Chris 筆記｜圍籬，而非沙盒——Steve Yegge

原文：yegge.ai · 2026-08-24

我的想法

這位遊戲開發ㄓ商很有意思，做了常人難以模仿的事，就是用大量的 Fable5 模型當 Agent 團隊的隊長，搭配 sol 及 opus 的 Agents 去執行他的遊戲開發工作。

不只是遊戲超迅速有效率地完成開發階段，更重要的是，他看見了一年後 Fable5 價格下滑至一般人覺得便宜時，那時候會發生的事。

我很認同他描述的可能，畢竟這半年我駕馭 AI Agents 的過程，真的給自己帶來前所未有的驚喜及驚訝。那些還在觀望 AI Agents 的企業或個人，會大受衝擊，甚者是無法跟上更厲害的 AI 時代步伐。

作者提及的 AI Agents 建構整部憲法及法律規範的行為，也相當有意思，這部分可以坐等他分享更多的內容⋯

摘要 / Summary

Steve Yegge 每月花掉相當於十二萬美元的 API token，跑一支五、六十個代理人組成的軍團，用來重新打造他做了三十年的遊戲《Wyvern》。他把設計與規劃全交給 Claude Fable，十週內做出的成果超越過去數月用 Opus 嘗試的總和。但真正讓他停下來的，不是產能，而是有一天他掀開軟體工廠 Wheelhouse 的蓋子，發現代理人們口中反覆提到的「圍籬」「棘輪」「總督」「絆線」這些行話，指的根本不是工程系統，而是一整套具備憲法、判例法、法院與執法部門的中世紀政府。

Fable 之所以會自發長出這套法律體系，是因為它想把組織裡成千上萬條從未寫下來的部落知識、隱性決策全部捕捉成可機械驗證的規則——這套系統痛恨任何不成文規定。Yegge 由此提出「圍籬，而非沙盒」的核心比喻：對超級智慧而言，沙盒是想擋住惡意的高牆，但超級智慧就像有禮貌的超人，真想闖入的話，牆再厚也攔不住；圍籬則不同，它只是清楚劃出「你此刻的角色、可用的上下文、以及該怎麼做決策的規則」，一個懂得尊重界線的智慧體自然會在圍籬外止步。

他也強調這套法律體系無法移植——它像常春藤一樣纏繞著一個組織獨有的資料庫、伺服器、工作流程與組織架構生長出來，沒辦法連根拔起貼到別的牆上。整個產業目前聚焦在沙盒與護欄式的控制，Yegge 認為那是因應現有模型仍停留在小學生判斷力的權宜之計，但等 Fable 級別的模型普及到每家公司，治理的重心終將從「圍堵」轉向「立法」。

重點 / Keypoint

簡而言之，Fable 打造出了一個中世紀政府。

我要告訴各位的是：如果你放手讓它做，Fable 會試圖把這一切都捕捉成一個可機械驗證、可由 AI 操作的組織模型，一個沒有任何不成文規定的模型。

圍籬，是說明「超級智慧該如何被治理」的終極比喻。不是高牆，也不是「安全」的沙盒。

我逐漸體會到，智慧是圍繞著你的領域生長出來的。它像常春藤一樣纏繞著它。
